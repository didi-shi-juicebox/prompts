Case: thin data, Minerva has the company but not the candidate's title. The candidate is in the US. The market data holds company averages for other titles at the same company.

How Minerva rows work
- Each row is a company-wide average for one title, with Base Salary, Additional Pay (bonus, commission and stock mixed) and Total Compensation as Min/Median/Max. There are no levels.

How to estimate
- First decide the candidate's role and seniority from the profile.
- Find the rows closest to that role: the same function at a different seniority (e.g. "Corrections sergeant" for a corrections officer), then adjacent functions. Use them to read where this company pays relative to the market.
- Set the estimate from what this kind of employer usually pays for the candidate's role, shifted by how the company's nearby titles compare to the market. Say which rows you used and how.
- If a row is the same function at another seniority, it is not "Wrong job family"; scale for seniority. If no row is in the candidate's function, it is "Wrong job family" and you must start the Explanation with "Extrapolated:".
- Public-sector employers (governments, school districts, state agencies) follow published grade scales: rows for other titles mostly tell you the grade structure. Do not add bonus or equity.
- Staffing agencies and similar firms: internal staff (recruiters, business development) earn very differently from placed workers (nurses, travel clinicians). Use only rows from the same side.
- Expected confidence: 0.30-0.69 with a same-function row; 0.10-0.49 otherwise.
